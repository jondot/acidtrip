# Examples

Art made in acidtrip. Each piece ships in its source format (`.acid`, open it with `acidtrip <file>`),
as classic ANSI (`.ans`), and as PNG.

## Omarchy

Wallpapers and tee logos for [Omarchy](https://omarchy.org). Every wallpaper comes at its canvas size
plus 1920x1080, 2560x1440 and 3840x2160.

| Wallpaper | |
|---|---|
| `omarchy-quattro` | the Quattro jump from Omarchy's Tokyo Night background, redrawn as a sunset piece |
| `omarchy-outrun` | synthwave sun over a grid road |
| `omarchy-neon-city` | a neon skyline at night |
| `omarchy-jade-peaks` | layered mountains in jade mist |
| `omarchy-new-horizon` | a ringed giant rising over a moon |
| `omarchy-industrial-moon` | a harvest moon behind a refinery |

![Quattro](omarchy/wallpapers/omarchy-quattro-1920x1080.png)
