# Library flows

Multi-step user flows for the Gallery, the sourcing studio, fonts, stencils,
patterns, brushes, image import, the AI and sharing. Run them with

    ACIDTRIP_FLOWS=library/ cargo test -p acidtrip --test flows

Files a flow writes live under `/tmp/acidtrip-flows/library-NN/`. The fake
Claude API responses are in `fake/`.

| Flow | Steps (short) | Covers | Found |
|---|---|---|---|
| 01_gallery_remix | add a folder (bad path, Esc, relative path) → grid → view → open as document → draw → save → restart → Continue → reopen the file | Gallery local folders, remix, restart | A bad path cleared what you typed; Esc in the folder field closed the whole Gallery; relative folders were stored as typed and broke from another directory |
| 02_gallery_collection_restart | keyboard only: collect → collect again → Esc at every level → restart offline → open the collection copy → `c` takes it out | collection, offline, Esc paths | The `c` label said "save" on pieces already kept |
| 03_gallery_take_mouse | one button: sidebar Gallery → add a folder by card/button → click a piece → drag a part → stamp twice → sidebar ✂ take → sidebar studio | mouse-only Gallery, take a part, sidebar | The sidebar's "studio" ignored the selected piece |
| 04_gallery_studio_font_stamp | Gallery piece → studio → box, wand and lasso letters → save font → Font tool → stamp a word → undo/redo → save | Gallery → studio → Font tool | — |
| 05_stencil_save_restart | draw → select → block menu → save stencil (Esc, duplicate name) → restart → search → stamp → Ctrl-D delete with the search kept → restart | stencils by keyboard, restart | Deleting a stencil lost the search |
| 06_stencil_mouse_only | paint → select → SELECT panel ♣ → chooser by clicks → stamp → delete by button → close by button | stencils by mouse only | No mouse way to delete a stencil |
| 07_studio_unhappy | keys with no selection → Enter with no letters → same letter twice → delete a letter → undo → Esc with unsaved letters → back in → close with unsaved letters | cutter unhappy paths | Esc/close silently dropped unsaved letters; a second letter with the same name silently replaced the first |
| 08_studio_source_myfonts | palette → non-art file → missing path → real file → cut H, I → save → Ctrl-S stencil → My fonts delete/undo → Font tool → words with missing letters → stencil from N | studio sources, My fonts, Font tool | A load error named the path twice; the Font dialog didn't say which letters were missing; "nothing to stamp" closed the dialog |

| 10_pattern_save_restart | type a motif → use as pattern (none selected first) → paint → save (Esc, empty, name, same name, built-in name) → restart → ★ → paint → delete → built-in back | patterns, restart | Saving silently overwrote a pattern or shadowed a built-in |
