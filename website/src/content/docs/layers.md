## The LAYERS panel

Each layer in the sidebar shows a thumbnail, with buttons to add, duplicate, delete, move and merge.

| Key | What it does |
|---|---|
| <kbd>Alt-↑</kbd> / <kbd>Alt-↓</kbd> | select the layer above / below |
| <kbd>Alt-Shift-N</kbd> | add a layer |
| <kbd>Alt-Shift-D</kbd> | duplicate the layer |
| <kbd>Ctrl-L</kbd> | the full Layers panel |

## The full Layers panel

<kbd>Ctrl-L</kbd> opens every layer with a large thumbnail and every layer action in one place.

![The Layers panel with thumbnails for each layer](/shots/layers-panel.png "Ctrl-L: every layer and every layer action.")

| Key | What it does |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> | select a layer |
| <kbd>Shift-↑</kbd> <kbd>Shift-↓</kbd> | move it up / down |
| <kbd>]</kbd> <kbd>[</kbd> | move it up / down |
| <kbd>N</kbd> | new layer |
| <kbd>D</kbd> | duplicate |
| <kbd>X</kbd>, <kbd>Delete</kbd> | delete |
| <kbd>V</kbd> | show / hide |
| <kbd>L</kbd> | lock |
| <kbd>F</kbd> | reference: shown dimmed, never exported |
| <kbd>R</kbd> | rename |
| <kbd>M</kbd> | merge down |

## Reference layers

A reference layer is shown dimmed for tracing and never exported. Palette › *Add reference image layer…* imports a picture as one, and <kbd>F</kbd> in the Layers panel turns any layer into a reference.

Palette › *Clear layer* empties the current layer.

## The minimap

The sidebar's MAP shows the whole piece with your view highlighted. Click or drag it to jump, and <kbd>Alt-M</kbd> toggles it.

Frames each have their own layers. See [Animation](/docs/animation/).
